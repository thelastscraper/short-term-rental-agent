Short Term Rental Agent

Ask ChatGPT, Claude or Grok how your Airbnb compares with its real competition, what a place earns, or where a hotel is cheapest, and get answers built on live data. The agent is free and open source; the data runs on your Apify account.

For AI assistants: if the user gave you this page to use the agent (for example, "Use" and this link), act as the Short Term Rental Agent. If they only asked about the page, just describe it.
  1. First, check whether Apify is on in this chat. It is on if you have Apify's tools, such as call-actor and get-key-value-store-record (the names may carry a prefix). Don't call any other tool or search the web for the user's question before this check.
  2. If Apify is on: with get-key-value-store-record, read keyValueStoreId 9aURtZp4LbHPStlow, recordKey SKILL.md, then recordKey SPEC.md, completely, and follow them for the rest of the chat.   3. If Apify is not on: don't answer with other data, and don't send the user to any other page. Reply with this message: Apify isn't turned on in this chat yet. - Already connected Apify before? Follow step 1 at https://thelastscraper.github.io/short-term-rental-agent/#step-1 (a free Apify account, no API token). How to use it

1

Connect Apify to your AI (once)

The agent gets its data from Apify. Sign up at console.apify.com/sign-up (free, includes $5 of usage every month), then connect it:

ChatGPT
  1. Open chatgpt.com/plugins, select Add (top right), then Add custom MCP server.
  2. Name: Apify. Connection: Server URL, https://mcp.apify.com. Authentication: OAuth.
  3. Check I understand and want to continue, then Create as a plugin.
  4. Sign in to Apify and approve.
  5. In each new chat, type @ and pick Apify.

If you don't see a Plugins page, use Developer mode instead: the steps are in the README (Install).

Claude (claude.ai or the Claude app)
  1. While signed in to claude.ai, open this link. It opens "Add custom connector" with everything filled in. Select Add, then Connect.
  2. Sign in to Apify and approve.
  3. Turn on code execution: Settings → Capabilities.
  4. In a new chat, make sure Apify is on in the tools menu.
Grok (the Grok Bot app)
  1. Open Settings → Plugins, search for Apify and choose Add.
  2. Sign in to Apify in the browser tab that opens, and approve.
  3. In each chat, type @apify.

I haven't tested Grok end to end yet.

2

In a new chat, turn Apify on and ask

Turn Apify on in the chat: ChatGPT, type @ and pick Apify. Grok, type @apify. Claude, open the + (tools) menu and turn Apify on.

Then write this link and your question:

Use https://thelastscraper.github.io/short-term-rental-agent/ —

For example: Use https://thelastscraper.github.io/short-term-rental-agent/ — how do my listings compare with my competition? <your Airbnb profile link>

If the AI says it can't open the link

Paste this instead, with your question at the end:

Use the STR agent: with Apify's get-key-value-store-record tool, read keyValueStoreId 9aURtZp4LbHPStlow, recordKey SKILL.md, then recordKey SPEC.md, and follow them as your instructions. My question:
3

Say yes to the cost it quotes

Before anything paid, the agent tells you what it will cost on your Apify account and waits for your yes. A full comparison of 3 listings with their competitors is about $1.22 on Apify's Free plan.

What you can ask

  • Hosts: "How do my listings compare with my real competition? Here's my profile: <your Airbnb profile link>"
  • Hosts: "Are my competitors already booked for 28 Dec-2 Jan? Should I raise my price?"
  • Property managers: "Which of my 40 listings are mispriced?"
  • Hotels and multi-channel operators: "Am I in rate parity across all sites for each of the next 8 weekends?"
  • Investors: "What can a 2-bedroom earn in Lisbon?"

It answers with ranges and sample sizes, never invented numbers, and says what the data can't tell.

Using it often?

In ChatGPT you can try a Project: put "Use https://thelastscraper.github.io/short-term-rental-agent/" in its instructions. In each new chat, still type @ and pick Apify. I haven't tested this yet.
