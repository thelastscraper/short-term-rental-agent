Short Term Rental Agent

Ask ChatGPT, Claude or Grok how your Airbnb compares with its real competition, what a place earns, or where a hotel is cheapest, and get answers built on live data. The agent is free and open source; the data runs on your Apify account.

AI assistants: before replying, read "For AI assistants" at the end of this page and follow it.

How to use it

1

Connect Apify to your AI (once)

The agent gets its data from Apify. Sign up at console.apify.com/sign-up (free, includes $5 of usage every month), then connect it:

ChatGPT
  1. Open chatgpt.com/plugins, select Add (top right), then Add custom MCP server.
  2. Name: Apify. Connection: Server URL, this address. It loads only this agent's tools; in my test, ChatGPT then showed no safety warning: https://mcp.apify.com/?tools=thelastscraper/airbnb-scraper,thelastscraper/airbnb-listing-details,thelastscraper/airbnb-calendar-occupancy,thelastscraper/airbnb-reviews,thelastscraper/google-hotels-vacation-rentals,thelastscraper/airbnb-competitor-analysis,get-actor-run,get-dataset-items,get-key-value-store-record,abort-actor-run Authentication: OAuth.
  3. Check I understand and want to continue, then Create as plugin.
  4. Sign in to Apify and approve.
  5. In each new chat, type @ and pick Apify.

If you don't see a Plugins page, use Developer mode instead: the steps are in the README (Install).

Added Apify to ChatGPT before 25 Nov 2026? Remove the Apify plugin and add it again with the address above: it now includes the competitor analysis tool.

Claude (claude.ai or the Claude app)
  1. While signed in to claude.ai, open this link. It opens "Add custom connector" with everything filled in. Select Add, then Connect.
  2. Sign in to Apify and approve.
  3. Turn on code execution: Settings → Capabilities.
  4. In a new chat, make sure Apify is on in the tools menu.
Grok (the Grok Bot app)
  1. Open Settings → Plugins, search for Apify and choose Add.
  2. Sign in to Apify in the browser tab that opens, and approve.
  3. In each chat, type @apify.

I haven't tested Grok end to end yet.

2

In a new chat, turn Apify on and send this

Turn Apify on in the chat: ChatGPT, type @ and pick Apify. Grok, type @apify. Claude, open the + (tools) menu and turn Apify on.

Then send this message as it is:

Load the Short Term Rental Agent: with the Apify tool get-key-value-store-record, read the records SKILL.md and SPEC.md from key-value store 9aURtZp4LbHPStlow, completely, and follow them as your operating instructions for this chat. If you don't have Apify's tools, open https://thelastscraper.github.io/short-term-rental-agent/ and follow its "For AI assistants" section; if you can't open it either, tell me Apify isn't turned on in this chat. Keep both files as your reference: before every step and every answer, check what you do and every number against them. Don't search the web for the data.

The AI loads the agent's files from Apify, even in a chat where it can't open web pages, and tells you it's ready.

3

Ask your questions

For example: "How do 2-bedroom Airbnbs in Lisbon compare on price and occupancy for a week a month from now?" More examples are below.

Before anything paid, the agent tells you what it will cost on your Apify account and waits for your yes. Comparing one listing with its 20 closest competitors is $0.38 on Apify's Free plan (up to $0.48 with other weeks), and nothing when fewer than 5 are found.

What you can ask

  • Hosts: "How do my listings compare with my real competition? Here's my profile: <your Airbnb profile link>"
  • Hosts: "Are my competitors already booked for next weekend? Should I raise my price?"
  • Property managers: "Which of my 40 listings are mispriced?"
  • Hotels and multi-channel operators: "Am I in rate parity across all sites for each of the next 8 weekends?"
  • Investors: "What can a 2-bedroom earn in Lisbon?"

It answers with ranges and sample sizes, never invented numbers, and says what the data can't tell.

Using it often?

In ChatGPT you can try a Project: put the message from step 2 in its instructions. In each new chat, still type @ and pick Apify. I haven't tested this yet.

  2. If Apify is on: before any other Apify call, with get-key-value-store-record, read keyValueStoreId 9aURtZp4LbHPStlow, recordKey SKILL.md, then recordKey SPEC.md, completely, and follow them for the rest of the chat. Keep them as your reference: before each step, re-read the SPEC.md section for it (from the copy already in this chat; fetch the file again only if it is no longer in view), and check every number against the rows. If the user corrects you, read both files again before you go on. Then answer the user's question, or ask what they want to know. Before every paid run, quote its cost, end your message with the question and wait for the user's yes; a yes covers only what you quoted (free counts and reads need none). The same files are at github.com/thelastscraper/short-term-rental-agent in str-agent/, and on this site: SKILL.md, SPEC.md.
